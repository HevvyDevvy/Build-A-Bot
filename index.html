Write the function, then run the tests.

Commands (one per line, # starts a comment)

forward 50 back 50 drive that many pixels (humanoids: walk 50)
turn 90 clockwise degrees, negative is anticlockwise
wait 5 pause in tenths of a second
arm down / arm up · spin on / spin off · wave · say hello

Logic
repeat 4 … end
forever … end
if wall_ahead … else … end

Conditions: wall_ahead and enemy_ahead (Distance Sensor), human_ahead (Vision Camera), bumped (hit something).

Levels: some cap your line count (use repeat), some forbid parts, and gates need the right action at the right moment.
